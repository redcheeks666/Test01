# 《天问》剪辑节奏与动效设计

本文是 `PLAN_v2.md` 的配套文档。PLAN 定"拍什么、放什么"，本文定"怎么剪、怎么动"。目标只有一个：**画面跟着音乐呼吸，有冲击感，看不出一张是"放照片"。**

---

## 一、六条总原则

1. **音乐先行，剪辑点全部落在拍子上。** BGM 由我用代码作曲，先定每章的速度和小节结构（见第三节），再按拍点剪。切镜头落在拍上，冲击落在强拍上，变速斜坡跨一个完整的小节。
2. **每 20—30 秒必须有一个"事件"**：英雄时刻、静音、分屏、变速、风格切换，不让观众进入"看幻灯片"的平稳状态。
3. **张力要有起伏**，不能一直满。静音和慢镜头是为了让后面的冲击更重。全片张力曲线见第二节。
4. **速度服从情绪**：要震撼就先慢后快，或者在冲击瞬间骤然放慢（英雄时刻）；要紧迫就加速、缩短镜头；要庄严就放慢、拉长。
5. **照片不是幻灯片**：每张照片都要指定一种运镜手法（见第五节），禁止匀速的平推平拉；相邻两张的手法、时长、运动方向都不能一样。
6. **好素材集中火力**：高清的好图给长镜头和英雄时刻，低清或一般的图只做快切、分屏、小画幅。

## 三、音乐结构（剪辑的拍子网格）

我用代码作曲，下面的速度就是剪辑网格。一拍的时长 = 60 ÷ BPM 秒；全片 30fps，下表给出每拍对应的帧数，剪辑点按帧对齐。

| 段落 | BPM | 一拍 | 节拍与配器 | 剪辑节奏 |
| --- | --- | --- | --- | --- |
| 序章 | 60（心跳） | 30 帧 | 低频脉冲 + 打字声；点火处重击；倒带处音频倒放 | 点火前每 2 拍一个画面；点火落在强拍上 |
| 壹 神话 | 72 | 25 帧 | 箫 + 古琴，五声音阶，自由流动 | 长镜头为主，4—8 拍一个镜头；飘带的运动对齐乐句 |
| 贰 仰望 | 84 | ≈21.4 帧 | 弦乐进入，钟表般的拨弦重音 | 2—4 拍一切；浑仪的环圈每拍转一格 |
| 叁 先驱 | 96 → 112 渐快 | 18.75 → ≈16 帧 | 定音鼓加入，越来越密 | 前半 4 拍一切，后半 2 拍一切；音爆落在强拍上，后接一拍完全静音 |
| 肆 4A—4B | 120 | 15 帧 | 打击乐驱动；4B 第一次大高潮 | 4A 每拍一切；4B 升空前 4 小节渐强 |
| 肆 4C—4D | 120，半速感 | 15 帧 | 鼓组撤掉，只留弦乐 | 4—8 拍一切；暗淡蓝点处全部静音约 6 秒 |
| 肆 4E—4F | 128 | ≈14 帧 | 民乐与电子融合，鼓组重新进来，持续加速 | 4F 每 2 拍一切，最后 4 个镜头每拍一切 |
| 伍 | 100，半速重拍 | 18 帧 | 管弦 + 合唱感铺底，鼓在 2、4 拍砸下，史诗感 | 英雄时刻的冲击都落在小节第一拍 |
| 尾声 | 自由速度 | — | 箫声主题回归，锣声收尾 | 跟着乐句走 |

剪辑时先输出一份"拍点表"（每个强拍、每个小节起点的帧号），所有切点、冲击帧、字幕入场都从这张表里取。

## 四、动效工具箱

### 4.1 视频变速

| 手法 | 做法 | 用在哪 |
| --- | --- | --- |
| **英雄斜坡** | 常速 → 冲击瞬间骤降到 0.2—0.4 倍 → 停留 1—2 拍 → 斜坡加速回 1—1.5 倍。斜坡曲线用缓入缓出，不用线性 | 点火、离塔、筷子合拢、溅落入水 |
| **冲刺斜坡** | 0.5 倍 → 在 1 小节内加速到 2—4 倍，配上升音效（riser），在强拍上硬切 | 进入高潮前、转场前 |
| **顿帧** | 冲击帧定格 2—4 帧，叠白闪或负片闪 | 点火、音爆、筷子夹住的那一下 |
| **倒放加速** | 倒放 2 倍 → 8 倍，中间按十六分音符插入卡顿帧 | 序章倒带 |
| **慢速漂移** | 0.5—0.7 倍，长时间保持 | 太空画面、地落、溅落降落伞 |

**变速的素材条件：**

- 60fps 的素材（NA-15 Artemis II 发射）可以干净地放慢到 0.5 倍；再慢就要补帧。
- 24/30fps 的素材放慢到 0.5 倍以下要用光流补帧（ffmpeg `minterpolate`，或 RIFE 之类的补帧模型），火焰和烟雾补帧后容易糊，所以尽量只在冲击瞬间短暂使用。
- NA-09 阿波罗 11 号本身就是高速摄影的慢镜头，不再放慢，反而可以在离塔后加速到 1.5—2 倍，制造"冲出去"的感觉。
- 4K 素材在 1080p 成片里有 2 倍的裁切余量，可以做虚拟推拉、虚拟震动、虚拟摇镜，不损失清晰度。

### 4.2 冲击与转场

| 手法 | 做法 |
| --- | --- |
| 冲击帧 | 强拍上 1—2 帧白闪或负片，配低频冲击音 |
| 镜头震动 | 冲击后 0.5—1 秒衰减震动；振幅跟着音乐的低频包络走 |
| 色散冲击 | 冲击瞬间 RGB 分离 3—6 像素，4 帧内回正 |
| 急推 | 0.3 秒内放大 1.2—1.5 倍，指数缓出（快速冲入后减速停住） |
| 甩镜转场 | 横向运动模糊 + 位移，前后两个镜头的运动方向一致 |
| 匹配剪辑 | 用形状或运动衔接两个画面：圆形月亮 → 圆形视场；火箭尾焰 → 下一枚火箭的尾焰；47 支火箭 → 33 台发动机 |
| 胶片烧穿 | 竞赛章 1957—1972 段落的转场：胶片过曝烧白 |
| 水墨晕染 | 中国事件的入场和退场 |
| 漏光扫过 | 情绪上扬的转场，伍章和尾声用 |

### 4.3 照片运镜（反幻灯片）

| 手法 | 做法 | 适合的照片 |
| --- | --- | --- |
| **细节拆解** | 一张超高清照片拆成 3—4 个局部，每拍切一个局部，最后一拍拉到全图 | 8000 像素级的照片：奥尔德林、莱特兄弟首飞 |
| **揭示** | 从一个局部细节开始，缓慢或冲刺式拉出全貌 | 热气球版画、STS-1 倒影 |
| **2.5D 视差** | 把主体从背景中抠出来（rembg 之类的工具或手绘遮罩），分层后做相对运动 | 主体清晰、背景干净的照片：哈勃与地球、地落、李林塔尔滑翔 |
| **元素动起来** | 抠出照片里的物体让它移动，配粒子或烟雾 | 戈达德的火箭升起；地落里的地球真的落下去 |
| **急推 + 漂移** | 强拍上急推进去，然后极慢地漂移 | 冲击类照片：X-1、冥王星 |
| **追踪平移** | 沿着画面里的线条（轨迹、桁架、地平线）移动 | 火星全景、空间站桁架、猎鹰 9 号长曝光弧线 |
| **光迹描绘** | 沿着照片里的轨迹用遮罩逐渐显示，像光被画出来 | 猎鹰 9 号发射与着陆的两道弧线 |
| **呼吸缩放** | 每个强拍放大 1—2%，然后回弹 | 快切蒙太奇中的照片 |
| **档案入场** | 照片以胶片片门、相框、剪报的形式从画外滑入，带投影 | 先驱章、竞赛章的历史照片 |
| **快闪拼贴** | 4—6 张相关照片每拍一张快速闪过 | 金唱片组照、中国火箭回收组照 |
| **分屏对照** | 两张照片左右或上下同步运动 | 1903 年、1970 年 4 月、2021 年春天 |

**照片运镜的规则：**

1. 缓动曲线：默认三次缓入缓出；冲击用指数缓出；只有太空漂移允许匀速。
2. 相邻两个镜头的手法、时长都不能一样；运动方向要么延续（上一个往右，下一个从左入），要么刻意对冲。
3. 时长按拍子网格取，同一段内要有长有短：0.5 拍的闪切、2 拍的普通镜头、8 拍以上的呼吸镜头都要有。
4. 每张照片停留时长 ≤ 4 秒，除非它是英雄时刻或呼吸镜头。

### 4.4 文字的节奏

- 大字关键词在强拍上入场：急推放大或打字机逐字出现。
- 一句解释延后半拍到一拍出现，小字再延后半拍。
- 日期戳配电传打字机音效，一个字符一帧。
- 文字退场比入场快：入场 8—12 帧，退场 4—6 帧。
- 英雄时刻里，文字在冲击后的慢镜头段落出现，不和冲击抢同一拍。

## 五、英雄时刻（逐帧设计）

全片 11 个英雄时刻，是剪辑上最花功夫的地方。

### H1 · 星舰点火（P-04 至 P-05，序章）
素材：SX-01（第 14 次试飞直播截取段）

1. 塔旁全景，心跳脉冲每拍一下，画面极慢推进。
2. 点火前半拍：画面和声音全部抽空（"吸气"）。
3. 强拍：点火帧 2 帧白闪 + 低频重击 + 色散冲击，镜头剧烈震动。
4. 火焰炸开的画面放慢到 0.3 倍，持续 2 拍，"124 米 · 人类造过最大的火箭"在慢镜头里入场。
5. 斜坡加速到 1.5 倍，星舰离塔、冲出画面，宏大和弦铺开。
6. "第一次，进入地球轨道"在下一个强拍入场。

### H2 · 倒带（P-06）
P-03 至 P-05 的画面倒放，2 倍加速到 8 倍；按十六分音符插入卡顿帧和 VHS 扫描线；年份数字跟着画面滚动，最后停在"公元前"，所有声音切断，接星空。

### H3 · 音爆（3-12，先驱章结尾）
素材：NA-20（只用上半部分的飞机）

1. 2 拍内照片持续加速推进，叠加横向速度线和运动模糊，配上升音效。
2. 强拍：音爆，白闪 + 震动 + 色散，"1.06 马赫"冲入画面。
3. 接着一拍完全黑场静音。
4. 下一个强拍，"竞赛"章节卡随定音鼓和铜管重音落下。斯普特尼克的"滴—滴"放到 4-02，配波形和字幕说明。

### H4 · 阿波罗 11 号升空（4-09）
素材：NA-09（00:18 点火，00:23—00:36 离塔，00:39 起升空）、AU-02 倒数

1. 倒数原声提前 4 小节铺进来，鼓组同步渐强，倒数的"Liftoff"落在高潮段第一拍。
2. 点火画面保持原速（本身就是高速摄影的慢镜头），方形胶片画幅带边框入画。
3. 离塔瞬间冲击帧 + 震动，第一次大高潮的主旋律进入。
4. 升空段加速到 1.5—2 倍，接全景。

### H5 · 一小步（4-11）
素材：NA-10_02 奥尔德林（5189×5067）、NA-10_01 脚印、AU-02

1. 音乐收成弦乐长音。
2. 奥尔德林做细节拆解：面罩反光里的登月舱和阿姆斯特朗 → 胸前的仪器 → 全身，每 2 拍一切。
3. "That's one small step…"原声响起时切到脚印，极慢推进 8 拍，最后定格。
4. "这枚脚印至今还在"在定格上出现。

### H6 · 暗淡蓝点（4-18）
素材：NA-14_02

1. 上一个镜头的最后一拍，所有声音同时切断。
2. 黑场 1 秒，然后画面淡入，用 6 秒极慢地推向那个像素。
3. 静音中，"60 亿公里外回望"逐字出现。
4. "这是我们的全部"出现后，单个钢琴音落下，音乐重新开始。

### H7 · 天问落在火星（4-26）
素材：CN-04_02 祝融号合影、NA-29 机智号影子

分屏同步呼吸缩放，锣声落在强拍时，第一章竹简上的"天问"二字沿弧线飞入，烙在祝融号上，水墨晕开。

### H8 · 筷子（5-04）
素材：SX-05（需要 Codex 补关键画面时码）

1. 助推器下落段常速，鼓点逐渐加密。
2. 机械臂开始合拢时斜坡降到 0.4 倍（24fps 素材需补帧，只用 1—2 秒）。
3. 夹住的那一帧：顿帧 3 帧 + 冲击音 + 震动。
4. 斜坡回到常速，"发射塔用'筷子'接住了火箭"入场。

### H9 · Artemis II（5-06）
素材：NA-15_01（60fps 4K）、NA-02_01—03 地落、NA-17_01 溅落

1. 点火放慢到 0.5 倍（60fps，画面干净），冲击落在强拍。
2. 斜坡加速到 2 倍离塔，在烟云最白的一帧做白场转场。
3. 白场褪去是地落（NA-02），2.5D 视差：月面边缘和地球分层，地球真的缓缓落到月球后面，0.6 倍速般的慢漂移。
4. 第一章的阿尔忒弥斯陶瓶画像以金色线描叠在月面上，"阿尔忒弥斯，是阿波罗的孪生姐姐"出现。
5. 溅落：镜头跟着三顶降落伞缓缓下移，入水那一下切到海面画面，冲击音。

### H10 · 星舰回到序章（5-07）
素材：SX-01、SX-03

1. 构图、机位和序章 P-03 完全一致，序章的打字声再响一次。
2. 点火的处理和 H1 相同，但这次不倒带：斜坡加速一路冲上去。
3. 冲刺斜坡加速到 4 倍穿过云层，强拍白场。
4. 白场褪去是在轨画面，地球边缘和星链卫星，转为 0.7 倍慢漂移，全片最高潮。
5. "现在，你知道这一步有多远了"在最高潮后的第一个长音里出现。

### H11 · 47 → 33（E-01）
代码线描的 47 支火箭排成圆阵，在强拍上收缩、重组，匹配剪辑成 SX-06 的 33 台猛禽发动机仰视照片，低频冲击 + 漏光扫过。

### 肆 · 竞赛

## 七、技术实现

- **工具链**：Python 生成拍点表和关键帧数据 → ffmpeg 做变速、补帧、裁切、调色 → 代码合成层（动效、文字、HUD、粒子）→ ffmpeg 输出 1080p30 成片。
- **变速**：对时间轴做重映射（每个输出帧对应一个源时间点），斜坡曲线用缓入缓出函数生成，补帧用 `minterpolate` 或补帧模型。
- **虚拟运镜**：4K 素材和高清照片在 1080p 画布里做裁切动画；震动是叠加在裁切框上的衰减噪声。
- **2.5D**：主体抠像生成前景层，背景层用修补填充主体留下的空洞，两层以不同速度运动。
- **验证**：每章先输出低分辨率预览，配上 BGM 检查卡点；卡点误差超过 1 帧就调整。
