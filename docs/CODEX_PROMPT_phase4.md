# 任务：《天问》嫦娥四号、祝融号的非中国来源素材（阶段四）

目的：片中嫦娥四号（CN-03）、祝融号（CN-04）两个镜头现在用的是国家航天局官网图。用户决定改用非中国来源、许可清楚的素材。

仓库：`https://github.com/redcheeks666/Test01`，分支：`claude/hello-nv3sez`。开始前先 `git pull --rebase origin claude/hello-nv3sez`。入库规则、命名、manifest 字段沿用 `docs/CODEX_PROMPT_phase2.md` 和 `phase3.md`：原件不转码，超过 95 MB 按 90 MiB 分片并附 sha256，每个文件在 `assets_review/manifest.csv` 占一行，许可依据贴原文链接。

## 先说明一个事实

嫦娥四号、祝融号在月面和火星表面的近景照片，只有中国的相机拍过。NASA、ESA、行星协会、维基百科等网站转载的这类照片，版权仍属国家航天局，**不算非中国来源，不要收**。

非中国来源只有下面两类：轨道器从上方拍的实拍，以及个人拍摄的展览实物模型照片。

## A. 必须：轨道器实拍的完整观测（做成和嫦娥六号一样的"从轨道上推近"镜头）

阶段三的 NA-33（LROC 加工图，有版权）和 NA-34（HiRISE 小裁切图，713×657）太小，没法推近。这次要**原始观测产品**，像 NA-32/02 那样，能从大范围一路推到探测器。

| 编号 | 内容 | 要求 |
| --- | --- | --- |
| NA-35 | HiRISE 拍到祝融号着陆平台与火星车的完整观测：ESP_069665_2055（2021-06-06），以及 ESP_069731_2055（2021-06-11，火星车已移动） | 从 uahirise.org 的观测页下载**全分辨率彩色产品**（RGB 或 IRB 的 JP2 / 大尺寸 JPEG）。公有领域，署名 NASA/JPL-Caltech/University of Arizona。如有后续能看到车辙的观测，列为候选。 |
| NA-36 | LRO 窄角相机拍到嫦娥四号（冯·卡门撞击坑）的观测原始产品 | 找 2019 年 1—2 月拍到着陆器与玉兔二号的观测编号，以及之后分辨率更高或太阳角更低（有影子）的观测。从 LROC 的 **PDS 数据产品**下载（条款里 PDS 数据为公有领域，NA-32/02 就是这样取的）。不要 Featured Images 的加工图。 |

每个文件在 key_moments 里写出探测器在图中的像素坐标（着陆平台、火星车、着陆器、玉兔二号分别写），以及图像朝向（北在哪边）。

## B. 可选：展览中的实物模型照片

个人拍摄、明确开放许可（公有领域 / CC0 / CC BY / CC BY-SA）的**全尺寸模型或复制品**照片：嫦娥四号着陆器、玉兔二号、祝融号火星车。去 Wikimedia Commons、Flickr 找，逐个打开文件页核对许可和作者。description 里写明"展览模型，非实拍"。

不要收新闻机构、官方机构发布或转载的照片。Commons 如果又拦截你的 IP，就把核对过许可的文件页链接和原件直链列在 REPORT 里，用户会换网络手动下载。
