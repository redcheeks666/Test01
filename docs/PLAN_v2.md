## 三、视觉规范

### 画面两类

- **代码绘制**：神话、理论、传说，以及找不到合法素材的画面（例如 1969 年《纽约时报》的更正版面）。延续样片的画风。
- **真实素材**：官方实拍视频、照片、古籍扫描。Claude 负责调色、加颗粒、做转场、叠字幕，让它们和代码画面统一。

### 各章节的真实素材处理

| 章节 | 风格 | 处理方式 |
| --- | --- | --- |
| 序章、伍 | 现代高清，冷色光效，HUD | 夜色压冷蓝，火焰保留橙色；轻颗粒；等宽字体数据和细线 HUD；点火时闪白加镜头震动 |
| 贰 仰望 | 铜版画、星图手稿 | 古籍扫描保留纸张底色；用代码描线动画叠在扫描件上；手稿与 NASA 实拍对位叠化 |
| 叁 先驱 | 复古科幻海报、老报纸、蒸汽版画 | 棕褐或双色调；半色调网点、纸纹、暗角、轻微片门抖动；照片以"展品卡"或"剪报"的形式出现，配缓慢推拉 |
| 肆 竞赛 | 档案影像，**色彩随年代演进** | 1957—1972：黑白胶片颗粒、16mm 片门、档案编号印章、遥测曲线<br>1977—2003：褪色胶片彩色、轻扫描线<br>2012—2024：干净的数字画面加细线 HUD<br>中国事件：水墨晕染转场加线框描边（保留原第五章"国风与科技融合"的语言） |
| 尾声 | 回到全片统一的暖月色 | 代码画面和实拍叠化 |

### 文字与章节卡

- 文字分三级：**大字关键词** / 一句解释 / 小字细节（年份、数字、出处）。
- 章节卡统一模板：纸本底纹，大号汉字序数（壹—伍），下面是两字章节名，配红色印章。每张章节卡时长、动效和音效都一样。
- 竞赛章的日期戳统一用等宽大字，比如"1957.10.04"，配电传打字机音效。
- 涉及遇难事件（莱卡、联盟 11 号、挑战者号、哥伦比亚号）一律克制处理：不用爆炸慢镜头，用乘组合影、黑场和姓名，音乐收住。

## 六、素材交接流程

1. **阶段一（Codex，已完成）**：下载原素材，生成 manifest、INVENTORY、REPORT 和预览，推到 `assets_review/`。
2. **审核（Claude，已完成）**：见 `assets_review/REVIEW_claude.md`。阶段一原素材总共只有 1.38 GB，所以决定**原件无损入库，不做代理**。
3. **阶段二（Codex）**：按 `docs/CODEX_PROMPT_phase2.md` 把原件推到仓库的 `assets/`。不超过 95 MB 的文件直接提交，超过的按 90 MB 二进制分片并附 sha256；X 直播只无损截取关键段入库。同时按审核意见补充收集。
4. **剪辑（Claude，云端）**：拼回分片并校验，用原件完成剪辑、特效和最终渲染，输出成片。
